# Laundry-Wallah

A clean, modern, and responsive landing page for a premium laundry and dry cleaning service business. 

## 🚀 Features
* **Modern Hero Section:** Eye-catching headlines paired with a dynamic text-and-image split layout.
* **Responsive Flexbox Design:** Optimized to scale and display beautifully across desktops, tablets, and smartphones.
* **Modern UI Elements:** Clean navigation structure, styled call-to-action (CTA) buttons, and custom hover states.

## 🛠️ Built With
* **HTML5:** Semantic elements (`<nav>`, `<main>`, `<header>`) for solid document structure.
* **CSS3:** Custom styles utilizing Flexbox layout models and CSS media queries.

## 📂 Project Structure
```text
├── index.html   # Main structural structure & content
└── style.css    # Typography, positioning, themes, and responsiveness
```

## 💻 Getting Started
1. **Clone or Download** the repository files to your local computer.
2. Ensure both `index.html` and `style.css` are saved together in the exact same directory.
3. Open `index.html` directly in any web browser (Chrome, Firefox, Safari, Edge) to view the live webpage.
